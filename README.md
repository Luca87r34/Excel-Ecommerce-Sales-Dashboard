# 📊 E-Commerce Sales & Profit Dashboard (Excel)

## 🎯 Project Overview
An interactive Excel dashboard designed to analyze e-commerce sales performance, profitability, and customer channel distribution. 

## 🛠️ Key Features
- **Dynamic KPI Cards:** Real-time metrics for Total Revenue, Total Profit, and Profit Margin %.
- **Interactive Slicers:** Global filtering by Region, Channel, and Product Category.
- **Pivot Tables & Charts:** 
  - Revenue & Profit by Category (Column Chart)
  - Monthly Sales Trend (Line Chart)
  - Sales Distribution by Channel & Region (Bar Chart)

- `Dati_Grezzi`: Raw transactional data formatted as a Native Excel Table.
- `Calcoli_Pivot`: Underlying Pivot Tables and dynamic calculations.
